What it does, step by step

01

Launch headless Chromium

Playwright starts a real browser engine with no visible window, so pages that need JavaScript render exactly as a user would see them.

02

Navigate and read the title

Waits for domcontentloaded with a 30-second ceiling, then reads page.title() and prints it — a cheap check that the right page really loaded.

03

Capture the whole page

Pauses 3 seconds for late-loading content, then writes a full_page screenshot — the entire scroll height, not just the viewport.

The core of it

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    try:
        page = browser.new_page()

        print(f"🌐 Navigating to: {TARGET_URL}")
        page.goto(TARGET_URL, wait_until="domcontentloaded", timeout=30000)

        page_title = page.title()
        print(f"✅ Successfully reached the site: {page_title}")

        # Short wait for dynamic content on the page to load
        page.wait_for_timeout(3000)

        page.screenshot(path=OUTPUT_PATH, full_page=True)
        print(f"📸 Screenshot saved: {OUTPUT_PATH}")
    finally:
        browser.close()
